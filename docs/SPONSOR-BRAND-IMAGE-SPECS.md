# Sponsor Brand Image Specifications

When uploading a sponsor brand logo for quizzes, use these specifications:

## Dimensions
- **Recommended**: 200×200 px (square)
- **Maximum**: 400×400 px (square)
- **Aspect ratio**: 1:1 (square) for consistent display

## File Size
- **Maximum**: 500 KB

## Formats
- PNG
- JPG / JPEG
- WebP

## Display
The logo is displayed at approximately 40×40 px throughout the quiz (header, question cards, completion screen). A square image ensures proper cropping and clarity.
